Модули проекта

Дашборд академии

Главный экран приложения. Открывается при запуске и отображает бюджет, рейтинг академии, краткий список игроков и ближайшие турниры. Все виджеты кликабельны — нажатие переводит в соответствующий раздел. Данные обновляются автоматически при каждом игровом событии.

Тулбар навигации

Панель вкладок в верхней части экрана: Главная, Игроки, Турниры, Тренировки, Финансы, Инфраструктура. Нажатие на вкладку загружает соответствующую панель. Активная вкладка выделяется цветом.

Календарь турниров

Отображает расписание турниров на текущий месяц в виде сетки. Дни с событиями выделены. Нажмите на день чтобы открыть карточку турнира с деталями: покрытие корта, призовые, уровень соперников. Переключение месяцев — стрелками влево и вправо.

Менеджер карьеры

Позволяет создать новую карьеру, указав название академии, имя менеджера и уровень сложности. Доступны три уровня: лёгкий (5 000 000 ₽), нормальный (2 000 000 ₽) и сложный (500 000 ₽). Карьера сохраняется через меню Файл → Сохранить.

Скаутинг

Панель скаутинга открывается через вкладку «Игроки». Позволяет искать молодых игроков по позиции, возрасту, рейтингу и региону. Для подписания контракта выберите игрока и нажмите «Предложить контракт».

Карточка игрока

Открывается при нажатии на имя игрока. Отображает характеристики (подача, форхенд, бэкхенд, выносливость, ментальность), информацию о контракте и историю тренировок.

Свойства академии

Раздел «Инфраструктура» показывает состояние объектов академии: стадион, тренировочная база, медицинский центр. Каждый объект можно улучшить за счёт бюджета. Уровень инфраструктуры влияет на качество тренировок и привлечение талантов.

Слайды и макеты

Модуль создания презентаций. Каждый слайд привязан к макету — шаблону расположения элементов. Доступны макеты: только заголовок, заголовок с контентом, два столбца, таблица статистики, карточка игрока, результаты турнира, пустой. Слайды можно добавлять, удалять, перемещать и дублировать.

Мастер-слайд

Задаёт глобальное оформление всей презентации: фон, логотип академии, нижний колонтитул, цветовую схему и шрифты. Все слайды автоматически наследуют стиль мастера. Изменение мастера применяется сразу ко всем слайдам.

Текстовый блок

Элемент для добавления текста на слайд. Поддерживает настройку шрифта, размера, цвета и выравнивания. Используется для заголовков, абзацев и подписей к статистике.

Изображение

Позволяет вставить на слайд фото игрока, логотип академии или тактическую схему. Поддерживает обрезку, изменение размера с сохранением пропорций и настройку прозрачности.

Фигура

Геометрические элементы: прямоугольник, круг, эллипс, стрелка, линия. Используются для тактических схем и оформления слайдов. Настраиваются цвет заливки, рамка и угол поворота.

Таблица

Элемент для отображения табличных данных: статистика игроков, результаты турниров, финансовые показатели. Поддерживает стили оформления и автозаполнение из данных академии.

Аудио

Добавляет звуковое сопровождение на слайд: гимн академии, фоновая музыка. Поддерживает форматы mp3, wav, ogg. Можно настроить автовоспроизведение, зацикливание и громкость.

Видео

Вставка видеозаписей на слайд: нарезки голов, тренировочные моменты, обзоры турниров. Поддерживает обрезку по времени — можно задать начало и конец воспроизведения нужного фрагмента.

Темы оформления

Встроенные темы: Academy Blue, Dark Stadium, Clean White, Trophy Gold. Каждая тема включает цветовую схему, набор шрифтов и фон. Применяется ко всей презентации через меню Дизайн → Применить тему.

Цветовая схема

Определяет основной, вторичный и акцентный цвета презентации, а также цвета результатов матчей: зелёный для победы, красный для поражения, серый для ничьей.

Фон слайда

Поддерживает четыре типа фона: сплошной цвет, градиент, изображение и паттерн (точки, линии, сетка). Фон задаётся через мастер-слайд или индивидуально для каждого слайда.
