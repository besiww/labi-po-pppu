Главный тулбар расположен в верхней части экрана. Он содержит вкладки для перехода между разделами приложения.

Дашборд

Дашборд открывается при запуске и отображает бюджет, рейтинг академии, список игроков и ближайшие турниры. Нажмите на любой виджет для перехода в соответствующий раздел.

Календарь турниров

Отображает расписание на текущий месяц. Дни с турнирами выделены. Нажмите на день чтобы открыть карточку события. Для переключения месяца используйте стрелки влево и вправо.
